الرابط اللي بيجيلك لما تنشر الـ Script كـ Web App

الأوراق اللي هتتعمل تلقائياً:

  • Reports — البلاغات والمشاكل
  • IDChanges — طلبات تغيير الـ ID
  • Welcomes — طلب الترحيب
  • Agents — حسابات الوكلاء
  • Admins — حسابات الأدمن

مسح جميع البيانات

هذا الإجراء سيحذف كل البيانات ما عدا حسابات الأدمن والوكلاء. لا يمكن التراجع!

ما سيتم حذفه:

  • جميع البلاغات والمشاكل
  • جميع طلبات تغيير الـ ID
  • جميع طلب الترحيب
  • أرشيف الترحيبات

ما سيتم الاحتفاظ به:

  • جميع حسابات الأدمن (الأسماء وكلمات المرور)
  • جميع حسابات الوكلاء (الأسماء وكلمات المرور وأرقام الواتساب)
  • جميع الأقسام والنقاط
  • إعدادات المدير وكلمة المرور
